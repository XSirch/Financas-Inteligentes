---
name: Escopo do agente financeiro
description: Público, integrações desejadas e autonomia definidos pelo usuário.
---

O usuário quer um app móvel Android de finanças para uso apenas dele, usando sua própria assinatura ChatGPT via Codex OAuth e MeuPluggy para conectar informações financeiras automaticamente. Confirmou que tem conta com acesso à API da Pluggy. O motor de IA deve funcionar online sem depender do computador dele.

Manter a assinatura ChatGPT e validar OAuth é requisito explícito; o usuário não autorizou substituição por uma API com cobrança separada.

O usuário aceita que o código seja aberto, mantendo seus dados privados, e pode usar um computador na configuração inicial. Essas escolhas foram feitas para explorar o caminho documentado de OAuth em servidor próprio remoto, ainda não validado na prática com sua conta.

As prioridades são gastos, cartões e assinaturas; orçamento, metas e previsões; investimentos e patrimônio. A autonomia escolhida é também organizar e criar alertas, não executar movimentações financeiras.

**Why:** escolhas expressas pelo usuário durante a definição do produto.

**How to apply:** manter esse escopo ao propor e construir a primeira versão. Ainda é necessário validar a compatibilidade da hospedagem remota pretendida com o uso oficial da assinatura ChatGPT; não substituir a integração de IA sem combinar com o usuário.
